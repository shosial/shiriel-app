# Shiriel Turgeman – האפליקציה

גיוס לקוחות, שיחות מכירה מנותחות וניהול לקוחות, במקום אחד. נבנית על בסיס "מערך גיוס לקוחות" של האקדמיה, כמוצר נפרד לעסק של שיריאל.

## איך זה אפליקציה
- **עכשיו: PWA.** אתר שמותקן למסך הבית באייפון ובאנדרואיד ונפתח כמו אפליקציה (מסך מלא, אייקון, עובד גם בלי רשת לשלד).
  - אייפון: Safari ← שיתוף ← "הוספה למסך הבית".
  - אנדרואיד: Chrome מציע התקנה, או כפתור "להתקנה" במסך הסקירה.
- **בהמשך: Capacitor.** אותו קוד עטוף לאפליקציה בחנויות של אפל וגוגל, עם הקלטה והתראות פוש.
- התשלום על הגישה נעשה באתר (דף תשלום של מורנינג), לא בתוך האפליקציה.

## מבנה
```
src/
  server.js          מפעיל את השרת
  app.js             בונה את האפליקציה (גם לטסטים)
  config.js          משתני סביבה
  http/security.js   כותרות אבטחה, CSP, שער /api (סגור כברירת מחדל), חסימת כתיבה מאתר אחר
  routes/            קובץ לכל תחום (כרגע: health.js)
  db/pool.js         חיבור ל-Postgres
  db/migrate.js      מריץ את כל קבצי db/schema לפי הסדר
  db/schema/         קובץ לכל תחום; 999-lockdown.sql (נעילת Supabase) תמיד אחרון
public/
  index.html, app.css, app.js   מעטפת האפליקציה (RTL, לשוניות למטה)
  manifest.webmanifest, sw.js   התקנה כאפליקציה ועבודה בלי רשת
  fonts/             Heebo (עברית) ו-Poppins (המיתוג), מוגשים מהשרת עצמו
  icons/             אייקוני האפליקציה (npm run icons)
test/                טסטים; routes.json = רשימת כל הנתיבים
```

## הרצה מקומית
```
npm install
cp .env.example .env   # למלא לפי הצורך; בלי DATABASE_URL השרת עולה בלי מסד
npm run dev
```

## טסטים
```
npm test
TEST_DATABASE_URL=postgres://...מסד-ריק-לבדיקה npm test   # גם הסכמה. מוחק את המסד! לעולם לא פרודקשן
```
נתיב שנעלם מכשיל את הטסטים. נתיב חדש נוסף לרשימה בכוונה: `npm run routes:update`.

## העלאה לאוויר (Render + Supabase)
1. **Supabase:** פרויקט חדש באזור Frankfurt. מעתיקים את ה-Connection string של **Session pooler**.
2. **Render:** New ← Blueprint ← הריפו הזה. `render.yaml` מגדיר שרת Starter בפרנקפורט, `npm run migrate` לפני כל עלייה ו-`/healthz`.
3. ממלאים ב-Render: `DATABASE_URL`, `PUBLIC_URL` (הכתובת ש-Render נותן, עד שיהיה דומיין), `ADMIN_EMAILS`.
4. פותחים את הכתובת: "מצב המערכת" צריך להראות "השרת והמסד פעילים".
