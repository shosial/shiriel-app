# האפליקציה (Expo)

האפליקציה לאייפון ולאנדרואיד, בנויה ב-Expo (React Native + Expo Router). אותו קוד רץ גם בדפדפן.
העיצוב לפי ההנחיות של אפל (Human Interface Guidelines): כותרות גדולות, רשימות מקובצות, סרגל לשוניות, SF Symbols, מצב כהה אוטומטי, מימין לשמאל.

כרגע המסכים מציגים **נתונים לדוגמה** (`src/data/demo.ts`). החיבור לשרת (תיקיית השורש של הריפו) מגיע בשלבים הבאים.

## לראות את האפליקציה באייפון (Expo Go)
1. להתקין את **Expo Go** מה-App Store בטלפון.
2. במחשב, בתיקייה `mobile`: `npm install` ואז `npx expo start`.
3. לסרוק את קוד ה-QR שמופיע במסוף עם המצלמה של האייפון. הטלפון והמחשב צריכים להיות באותה רשת Wi-Fi (אחרת: `npx expo start --tunnel`).

## בדפדפן
`npx expo start --web`, או בנייה סטטית: `npm run export:web`.

## מבנה
```
src/app/        מסלולים בלבד (Expo Router): לשונית לכל תחום, כל אחת עם Stack משלה
src/screens/    גוף המסכים
src/components/ רכיבים משותפים: רשימה מקובצת, אייקון, מסך, סרגל לשוניות (נייטיב + ווב)
src/theme/      צבעים (צבעי המערכת של iOS/Android) וסגנונות טקסט של אפל
src/data/       נתונים לדוגמה לדמו
```
